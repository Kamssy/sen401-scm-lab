# sen401-scm-lab
# SEN 401 SCM Lab – Student Records

A small modular Python project used to practise Software Configuration
Management with Git and GitHub.

## Project Structure
- `app.py` – main script that runs the demo application
- `students.py` – data module holding the student list and average calculation
- `utils/helpers.py` – helper functions (highest and lowest score)
- `requirements.txt` – project dependencies
- `README.md` – this file

## Usage
1. Make sure Python 3 is installed.
2. Install dependencies: `pip install -r requirements.txt`
3. Run the app: `python app.py`
